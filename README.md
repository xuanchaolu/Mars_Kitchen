# 火星小厨房 — macOS AI 对话客户端

**火星小厨房** — 一个参考 DeepSeek / 豆包界面的 macOS 桌面聊天应用（红色渐变主题，图标与对话头像取自透明底源图 `火星小厨房AI.png`），通过 **OpenAI 兼容接口** 连接 **DeepSeek 官方 API**（默认模型 `deepseek-flash`，即 DeepSeek flash v4.1），支持流式输出、深度推理（`reasoning_content`）与图片视觉输入。

![界面](https://img.shields.io/badge/platform-macOS%20arm64-blue) ![Tech](https://img.shields.io/badge/tech-Electron%20%2B%20SwiftUI--style-8b5cf6)

## 🍽 火星小厨房 人设架构（Skill.md + A.md / shtu + 档位映射）

火星小厨房 在 PerPer 全部既有能力之上，新增了「双人设 + 口味档位 + 忌口过敏」的 Agent 架构。

**完整 System Prompt 组装公式**（每次请求实时拼接，见 `renderer/js/mars.js`）：

```
System Prompt = Skill.md 全文                       ← 全局总能力、全局规则（所有版本共用）
              + 【A.md 或者 shtu 二选一】            ← 普通版 / 老年人版 人设
              + 档位映射规则                         ← 辣/甜/咸 + 忌口过敏 的参数映射
              + 用户当前参数快照                     ← 版本、辣度、甜度、咸度、忌口过敏
```

| 素材文件 | 作用 | 何时加载 |
| --- | --- | --- |
| `mars_profile/Skill.md` | 可用工具、固定执行流程、全局安全规则、输入输出格式、边界规则 | 所有版本 |
| `mars_profile/A.md` | 普通版人设：简洁现代、常规表达、无居家安全提醒 | 仅「普通版」 |
| `mars_profile/shtu.md` | 老年模式人设：**「您」称呼 + 通俗短句 + 煤气/用火安全提醒强制规则 + 高盐高糖高油提醒** | 仅「老年模式」 |
| `mars_profile/档位映射.md` | 辣度 0-4 / 甜度 0-4 / 咸度 0-4 的档位含义 + 忌口过敏全局约束 | 所有版本 |

**人群模式与口味参数**：主界面保持干净——不放参数栏、不放控制面板。
**第一次打开 App 时会弹出设置向导**，在里面完成：

| 项 | 说明 | 默认 |
| --- | --- | --- |
| 老年模式开关 | 一键切换 shtu / A.md：**整体放大字号**（含 AI 回答正文）+ 长辈称呼 + 居家安全提醒 | 关 |
| 辣度 / 甜度 / 咸度 | 各 0-4 档下拉 | 0 / 0 / 0 |
| 忌口 & 过敏 | 自由文本，全局约束 | 空 |

之后随时可在「设置 → 人群模式与口味」里修改（取消则回滚本次预览）。切换老年模式时弹窗内即时预览放大效果。

**边界规则**（已写入 Skill.md，并由前端在参数快照里给出判定）：

1. 辣/甜/咸档位**只对美食、菜谱类问题生效**；历史、常识类问题忽略这三项，仅保留人设与忌口过敏约束。
2. 忌口过敏是**全局约束**：任何涉及食材的回答都必须规避。
3. 老年模式只有「做饭 / 燃气用火」场景才强制追加煤气安全提醒；非厨房问题保持「您」称呼与通俗短句风格。
4. 普通模式（A.md）不会自动添加煤气、居家安全提醒。

**档位应用原则**（`档位映射.md` + 参数快照，避免机械套用档位）：

> 档位是「口味偏好**上限**」，不是「每道菜都必须达到」的指标。
> 菜品本身没有该味型时**不要强行加辣 / 加糖 / 加盐** —— 番茄炒蛋只有甜口与咸口，
> 用户即使选了中辣，也不要给番茄炒蛋加辣椒。
> 甜、咸都适用时**比档位高低**：甜度档位 > 咸度档位 → 建议甜口；咸度 > 甜度 → 建议咸口；
> 相同则按这道菜的传统口味推荐，并说明另一种做法也可以。
> 不适用时要一句话说明原因，不要沉默忽略。

**老年模式高档位健康提醒**：开启老年模式后，辣/甜/咸只要选到**最上面两档**
（3 特辣 / 4 爆辣、3 很甜 / 4 超甜、3 很咸 / 4 超咸），点「开始使用」或「保存」时会弹出**健康提醒**，
逐项说明肠胃 / 血糖 / 血压风险，并给出两个选择：

- **返回修改**：关掉提醒，留在弹窗里继续调档位（此时**不会**落库）；
- **确认并继续**：保留当前口味并保存。

**老年模式放大字号**：给 `<body>` 加 `elder-mode` 类，`style.css` 里对回答正文（14px → 19px）、
标题、表格、输入框、侧边栏、弹窗等统一放大（见 `body.elder-mode` 规则），无需重启、切换即生效。

**输出只有正文**：Skill.md 明确要求「只输出回答正文」，**不再输出** `【主体回答】` / `【提示信息】` 分段、
「当前生效参数：…」参数快照、「联网搜索调用次数：N次」计数。
模型若仍按旧格式输出，`Mars.parseOutput()` 会把标记与提示信息整段剥掉，前端只渲染正文。
对比型回答的 markdown 表格直接在气泡内渲染；联网搜索次数沿用 PerPer 的搜索框展示（「🔍 联网搜索 · N 次查询」）。

**人设文件可编辑**：首次启动会把随包的 `mars_profile/` 播种到
`~/Library/Application Support/火星小厨房/mars_profile/`，直接改这几份 `.md` 即可改变 Agent 行为，
设置面板里提供「打开人设目录 / 重新加载 / 恢复出厂人设」。

> 组装优先级（保留 PerPer 既有能力）：Mars 基础 Prompt（Skill + 人设 + 档位映射 + 参数快照）
> 永远在最前面；其后追加「启用的技能提示词」，没有技能提示词时追加「全局系统提示词」——
> 即技能提示词仍然优先于全局系统提示词。技能能力完整保留，但**不再随包内置任何技能**。

## 🔒 与 PerPer AI / 牛来 的数据隔离

**火星小厨房与 PerPer AI 完全独立，互不干涉：**

| 项 | 值 |
| --- | --- |
| 应用名 | `火星小厨房` |
| 数据目录 | `~/Library/Application Support/火星小厨房/` |
| PerPer AI 数据目录 | `~/Library/Application Support/PerPer/`（**不读取、不复制、不修改**） |
| 牛来 数据目录 | `~/Library/Application Support/牛来/`（**不读取、不复制、不修改**） |

- 早期版本启动时会「从旧版目录迁移设置/会话」，导致历史记录与 PerPer 重合 —— 该逻辑**已彻底删除**，
  `main.js` 里不再有任何 `PerPer` / `牛来` 路径引用。
- 数据目录名 = 应用名，由 `app.setName('火星小厨房')` 决定，因此天然与 PerPer 分属不同目录。
- 迁移 PerPer 数据时（例如只迁移 `avatars/`），可手动复制文件到自己的数据目录。
- E2E 会伪造 PerPer / 牛来的会话与配置放在同一个数据根下，断言应用**一条都不会读进来**，也不会改动原文件。

> 升级提示：本项目改过几次名字，早期版本的这些数据目录**都已不再使用**，可以自行删除（不删也没有影响）：
> - `~/Library/Application Support/Mars_Canteen/`（早期英文名 `Mars_Canteen` 版本）
> - `~/Library/Application Support/火星小食堂/`（上一次更名前命名为「火星小食堂」的版本）
> 当前版本只使用 `~/Library/Application Support/火星小厨房/`，且不会读取上面任何一个旧目录。

## ✨ 功能

- 🎨 **红色渐变主题**：强调色/发送按钮/用户气泡/品牌文字均为红色渐变；图标与对话头像为透明底 PNG（由 `火星小厨房AI.png` 生成）参考 DeepSeek 风格的聊天界面：侧边栏会话列表、欢迎页、消息气泡、Markdown 渲染、代码块一键复制
- ⚡ **流式输出**（SSE），逐字显示；可随时「停止生成」
- 🧠 **深度推理**：开启 `reasoning` 后显示「深度思考过程」——**思考中自动展开并实时流式显示**，**思考结束（开始输出答案）时自动折叠**，标签显示用时，点一下可再展开；并支持 `reasoning_details` 原样回传（模型可继续推理）
- 🧍 **3D 虚拟形象**：支持**多模型切换**（VRM 0.x / 1.0），自然站姿（手臂下垂 **自动校准**）、自动眨眼、呼吸起伏、视线跟随鼠标、说话时小幅手势；可在设置中一键关闭
- 🗣️ **语音播报**：AI 回答自动播报，口型按 Edge 词边界时间轴逐音节开合（每音节「张口→闭口」），播报结束自动闭嘴
- 🎙️ **Edge 神经语音**（默认）：微软神经网络语音，中英双语女声（晓晓 / 晓伊 / Ava / Emma 可选），自带依赖库、无需 API Key；不可用时自动回退系统语音
- 🧩 **技能（Skills）**：设置里可**安装技能**（文件夹 / `SKILL.md` / `.md` / `.zip`），每个技能有**独立开关**决定是否使用；技能还可选配一段**系统提示词**
  - **优先级**：启用技能若配了提示词 → **覆盖**全局系统提示词；未配 → 沿用全局（多个技能都配了则按顺序拼接）
  - 启用技能的说明（SKILL.md 正文）会作为「可用技能」注入到 system 消息中
  - 技能存放在 `~/Library/Application Support/火星小厨房/skills/<技能id>/SKILL.md`，可点「打开技能目录」直接管理
- 🌐 **联网搜索**（默认开启，无需任何 API Key）：DeepSeek 官方 API 本身**不提供**内置联网，火星小厨房 通过 **function calling + 内置 DuckDuckGo 搜索**实现——模型自主决定何时搜索（`web_search`）或读取网页（`fetch_page`），回答时在气泡里展示「搜索了几次 / 命中的来源链接」（来源可点击直接在浏览器打开）
  - 顶栏 🔍 一键开关；设置里可调「最多搜索轮次」（1~6，默认 3）
  - 搜索走主进程（无 CORS 限制），不需要任何第三方搜索 Key
- 📎 **上传图片 / 文本 / PDF**：点击回形针、直接粘贴或拖入输入框；图片以视觉格式发给模型，文本/PDF 提取正文内联发送
- 🔀 **多对话并行生成**：每个对话独立流式任务，切换对话互不打断；输入草稿、发送/停止按钮均按对话隔离
- 📁 **两种显示方式**（顶栏按钮一键切换）：
  - **列表模式**：左侧会话列表 + 主聊天区（经典布局）
  - **文件夹模式**：整个窗口变成文件管理器，每个对话是一个文件夹图标；**双击**在浮动窗口里打开对话（可多开、可拖动、可缩放）
  - **⌘C / ⌘V 分叉对话**：复制文件夹后粘贴即生成分支，**分支继承原文件夹图标**（并记录 `forkedFrom`）
  - 右键菜单：打开 / 复制 / 粘贴分叉 / **修改图标**（17 款可选）/ 重命名 / 删除
  - 每个对话在首次出现时**随机绑定一款文件夹图标**，之后固定不变
- 🔄 多轮对话、重新生成、复制消息
- 💾 会话历史自动保存在本机（`~/Library/Application Support/火星小厨房/conversations.json`）——**与 PerPer AI / 牛来 完全隔离，不读取也不迁移它们的任何数据**
- ⚙️ 设置面板：API Key、接口地址、模型、推理开关、Temperature、系统提示词、人群模式与口味、人设档案管理
- 🌙 跟随系统深色/浅色模式

### 🆕 火星小厨房 新增能力

- 🍽 **双人设系统**：普通版（`A.md`）/ 老年模式（`shtu`）二选一，与 `Skill.md`、`档位映射.md` 合并成完整 System Prompt
- 👴 **老年模式开关**：一键切换；**整体放大字号** + 长辈称呼（「您」）+ 通俗短句 + **做饭/燃气场景强制煤气安全提醒**
- ⚠️ **高档位健康提醒**：老年模式 + 辣/甜/咸最高两档 → 弹窗提示肠胃/血糖/血压风险，可「返回修改」或「确认并继续」
- 🍅 **档位不机械套用**：菜品不适合的味型不强加；甜咸都适用时按档位高低取口味（甜>咸→甜口，咸>甜→咸口）
- 🪟 **首次启动设置向导**：第一次打开 App 弹窗完成老年模式 / 口味档位 / 忌口过敏设置，主界面保持干净
- 🌶 **口味档位**：辣度 / 甜度 / 咸度 各 0-4 档，按档位映射规则约束菜谱输出（含高辣/高糖/高盐健康提示）
- 🚫 **忌口&过敏全局约束**：自由文本录入（如「虾过敏，不吃葱」），所有涉及食材的回答必须规避
- 🧾 **输出只有正文**：不再输出 `【提示信息】`/参数快照/搜索次数（模型若输出会被自动剥掉）
- 🧍 **火星姐默认在线**：VRM 形象默认显示、回答默认自动播报（可在设置里关闭）

## 🚀 使用

### 方式一：直接运行打包好的应用

```bash
open dist/火星小厨房.app
```

> 若首次打开提示「无法验证开发者」，在「系统设置 → 隐私与安全性」中点击「仍要打开」，或执行：
> ```bash
> xattr -dr com.apple.quarantine dist/火星小厨房.app
> ```

### 方式二：从源码构建

```bash
# 1. 安装依赖（首次需下载 Electron，约 100MB）
npm install

# 2. 构建 .app（生成图标 → 打包 → 签名）
bash build.sh
```

### 方式三：开发模式运行

```bash
npm start
```

## ⚙️ 连接配置（设置面板）

| 配置项 | 默认值 |
| --- | --- |
| API Key | DeepSeek 官方 Key（`sk-…`） |
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-flash`（DeepSeek flash v4.1）或 `deepseek-v4-pro` |
| 深度推理 | 开启 |

接口完全兼容 OpenAI Chat Completions 协议，也可改成任意 OpenAI 兼容网关（如 DeepSeek、智谱、本地 Ollama 等）。

请求示例（等价于应用内发送的请求）：

```bash
curl https://api.deepseek.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-你的KEY" \
  -d '{
    "model": "deepseek-flash",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true,
    "reasoning": {"enabled": true}
  }'
```

```bash
npm run test:e2e  # 端到端（45 项）：真实启动 Electron + Mock DeepSeek，
                  # 校验首次启动弹窗、老年模式字号、主界面无参数栏/控制面板、
                  # 火星姐默认在线、发出去的 System Prompt / tools、提示信息与表格渲染
```

E2E 会自动选空闲端口，并用 `MARS_APPDATA` 把数据根重定向到临时目录（不碰用户真实数据），断言：

- **首次打开**自动弹出设置向导，默认值 = 普通模式 / 辣0 甜0 咸0 / 忌口空
- **主界面没有**参数配置栏与 Control 控制面板；只有对话区 + 右侧火星姐面板
- 打开**老年模式**后整体字号放大（含弹窗与 AI 回答正文），写入后加载 `shtu`
- **火星姐模型显示 + 自动播报**默认开启
- 老年模式请求的 System Prompt = `Skill.md` → `shtu` → `档位映射` → 参数快照，且**不含** `A.md`
- 参数快照逐项等于弹窗/设置里选择的值（模式/辣度/甜度/咸度/忌口过敏）
- 联网搜索工具仍然下发给模型，且第二轮请求携带真实工具结果（计数 = 1）
- 回答里渲染出 `【提示信息】` 标准块与 markdown 表格
- **健康提醒**：老年模式 + 辣3/甜3 → 弹提醒并列出两项；「返回修改」不落库、「确认并继续」才保存；普通模式不弹
- **回答不含提示信息**：mock 故意返回带 `【提示信息】` 的旧格式，界面必须把它剥干净
- 在「设置」里关闭老年模式后字号恢复
- **数据隔离**：应用数据只落在 `appData/火星小厨房/`；伪造的 PerPer / 牛来 历史会话、API Key、模型设置都不会被读取，旧文件也不会被改动

## 🧩 技能（Skills）说明

**主文件识别（宽容）**：技能目录里的主文件可以是 `SKILL.md`、`SKILL.md（任意说明）.md`、任意 `SKILL*.md`，或目录内唯一的 `.md` —— 中文文件名也不会漏

**安装**：设置 → 技能 → 「＋ 安装技能…」，支持
- 文件夹（里面需有 `SKILL.md` 或任一 `.md`）
- 单个 `.md` / `SKILL.md` 文件
- `.zip` 压缩包（用系统 `unzip` 解压，自动寻找其中的 `SKILL.md`）

**SKILL.md 格式**（YAML frontmatter 可选）：
```markdown
---
name: 代码审查
description: 按团队规范审查代码，指出安全与性能问题
---
技能的具体指令正文……
```

**技能资源**：技能目录里的其它 `.md`/`.txt`/`.json` 等文件会作为「可用资源」注入清单；体积较小时（≤14KB）会**直接读进上下文**，体积大时模型可用 `read_skill_file` 工具按需读取（文件名不完全一致时自动模糊匹配）。

**开关与提示词**
| 技能状态 | 技能提示词 | 最终 system 消息 |
|---|---|---|
| 启用 | 已配置 | Mars 基础 Prompt + **技能提示词**（覆盖全局系统提示词）+ 技能说明 |
| 启用 | 未配置 | Mars 基础 Prompt + 全局系统提示词（沿用）+ 技能说明 |
| 停用 | — | Mars 基础 Prompt + 全局系统提示词（技能完全不注入） |

> Mars 基础 Prompt = `Skill.md` +（`A.md` / `shtu`）+ `档位映射.md` + 当前参数快照，永远在最前面。

## 🌐 联网搜索说明

- **为什么需要应用侧实现**：DeepSeek 的「联网搜索」只存在于它的网页版/App，官方 API 既不提供内置搜索，也不支持服务端搜索工具（实测 `plugins:[{id:'web'}]`、`web_search_options` 均被静默忽略）。好在 API **支持 function calling**，因此由应用代替模型去搜索。
- **工作方式**：模型需要实时信息时返回 `tool_calls` → 应用在主进程请求 DuckDuckGo 并解析结果 → 作为 `tool` 消息回传 → 模型基于资料作答（可多轮，默认最多 3 轮）。
- **多引擎搜索**：中文查询**优先百度**（对国内社区内容覆盖好），不足时自动换 DuckDuckGo、Bing 补齐；英文查询以 DuckDuckGo 优先。结果合并去重，界面会显示实际用了哪些引擎。
- **读页兜底**：直连被反爬拦截（如贴吧 403）时自动尝试文本代理；都失败会明确告知模型「改用搜索摘要作答」，避免它反复重试同一个打不开的链接。
- **DSML 兼容**：DeepSeek 有时会把工具调用写成内部标记语言（DSML）混在正文里，而不是标准 `tool_calls`。火星小厨房 会自动识别并解析成真实调用执行，同时把这些标记从回答里剥离（不会显示给你）；轮次用尽时会明确要求模型改用纯文本作答。
- **注意**：DuckDuckGo 为公开网页接口，解析规则可能随其改版失效；如需更稳定的结果，可换成 Tavily/Brave 等搜索 API（改 `main.js` 里的 `webSearch()` 即可）。

## 🧍 虚拟形象与语音播报

- **开关**：右上角「👤」切换形象面板；「🔊」切换自动播报；鼠标移到人物上会跟随视线，点一下会微笑
- **播报引擎**（设置面板）：
  - `Edge 神经语音`（默认）：微软神经网络语音，需联网，音质接近真人；支持中英混读
    - 晓晓（中文女声，温暖）· 晓伊（中文女声，活泼）· Ava / Emma（**中英双语女声**）
  - `系统语音`：macOS 内置语音，离线可用（语速可调）
- **口型同步**：播报时按真实音频时长驱动 VRM 的五个元音口型，并配合点头、轻微摆动与抬手小手势
- **姿态**：默认自然站姿（手臂下垂、肘部微曲、**左右完全对称**），加载时自动校准上臂方向与前臂弯曲方向（各模型骨骼朝向不同）
- **形象背景**：`火星姐` 专属 —— `bg/` 里的 3 张照片作为人物背后的背景（**每次打开随机一张**），切换到其他模型时自动不显示。图片放在 `renderer/assets/bg/bg-1..3.jpg`，想换图直接替换（保持文件名即可）
- **拖动旋转**：在人物上**左右拖动**即可水平旋转（±100°），双击复位正面；旋转时视线锁定不会乱甩，拖动不会误触表情
- **取景**：三分之四身（头部到裙摆 + 部分腿部），按模型包围盒与面板宽高比**自动计算相机距离**，换模型不用手动调；想更近/更远可改 `src/avatar-src.js` 里的 `frameH`（画幅高度比例，默认 0.73）与 `targetY`（中心位置，默认 0.665）
- **柔和面光**：正面主面光 + 面部补光 + 背后轮廓光（强度经实测标定：面部亮度提升约 20%，无过曝）
- **口型速度**：设置里的「口型速度」滑杆（很慢/慢/正常/较快/快），默认偏慢更自然；速度决定每个口型覆盖的字数与过渡平滑度

- **设置 → 人物模型**：下拉选择已导入的模型，立即切换（自动读取模型名、表情与口型名）
- **打开文件…**：从磁盘任意位置选择 `.vrm`，会复制到用户模型目录（`~/Library/Application Support/火星小厨房/avatars/`）并切换
- **打开模型目录**：把 `.vrm` 直接拖进去，再点「刷新列表」即可出现
- 内置 6 个模型（默认 **火星姐** `Martian.vrm`）：`Martian.vrm`（火星姐 · VRM 1.0）、`1620000625477528222`、`4961976968586841476`（林兰·希卡西）、`7062840423830520603`、`7779676433471406195`、`9140463356671483103`（Red）
- 显示名可在 `renderer/js/app.js` 的 `AVATAR_NAMES` 里覆盖（如 `'Martian.vrm': '火星姐'`）
- 兼容性：VRM 0.x 的 `a/i/u/e/o` 表情会自动映射为标准五元音；手臂静止姿态会在加载时**自动校准**（自动试出「手在肩下且贴身」的旋转方向）
- 关闭人物：设置里的「显示 3D 人物」取消勾选，或点顶栏 👤 按钮
